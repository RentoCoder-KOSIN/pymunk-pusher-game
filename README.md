# 🪙 Coin Pusher Game with Pymunk & Pygame

Pythonの物理演算ライブラリ `Pymunk` と描画ライブラリ `Pygame` を使用して作成する、2Dアーケード風コインプッシャー（コイン落とし）ゲームのプロジェクトです。

---

## 📌 プロジェクト概要

ゲームセンターにある「コインプッシャー」を物理演算で再現します。  
往復移動する台（プッシャー）の上にコインを投入し、コイン同士の押し合いによって手前の獲得口へ落とし、スコア（お金）を増やすゲームです。

---

## 🏗️ 必要な機能・要素一覧

### 1. ⚙️ 物理演算（Pymunk）
- **動く台（プッシャー）**
  - 前後に往復運動し、コインを押し出すオブジェクト (`KINEMATIC Body`)。
  - コインが滑り落ちずに台の動きに同期するよう、高い摩擦係数 (`friction`) を設定。
- **フィールド構造（台座・壁）**
  - 動かない床や段差構造 (`STATIC Body`)。
  - 左右へのコインの落下を防ぐ外壁。
- **コイン（メダル）**
  - 大量に生成されても安定して動作する円形オブジェクト (`Circle / DYNAMIC Body`)。
  - コイン同士の衝突、重なり、押し合いのシミュレーション。

### 2. 🕹️ ゲームシステム
- **コイン投入（シューター）**
  - プレイヤーの入力（クリック/キー操作）に応じた位置からコインを落とす機能。
- **判定・回収エリア**
  - **手前（獲得口）**: 落下したコインを消去し、スコアを「+1」加算。
  - **左右（回収口）**: 落下したコインを消去（アウト判定、スコア加算なし）。
- **所持メダル管理**
  - 現在の所持枚数を保持し、0枚になると投入不可になる仕組み。

### 3. 🎨 画面描画 & UI（Pygame）
- **グラフィック表示**
  - コインやプッシャーの見た目（テクスチャ/色）の描画。
- **UI（ユーザーインターフェース）**
  - 現在の所持枚数や獲得スコアのリアルタイムテキスト表示。
